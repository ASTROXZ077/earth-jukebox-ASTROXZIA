Methodology, Open Science & Attribution

About Earth Information Jukebox

Inspired by NASA's Earth Information Center and NASA Space Apps multi-sensory accessibility initiatives, the Earth Information Jukebox bridges visual data dashboards and auditory data sonification so that climate patterns can be intuitively heard as well as seen.

How Deterministic Sonification Works

  • No Randomization: Every data point is normalized cleanly between its historical minimum and maximum (t ∈ [0, 1]) and mapped directly to audio frequency (180 Hz – 780 Hz).
  • Click-Free Synthesis: Uses the native Web Audio API (OscillatorNode, GainNode, StereoPannerNode, and AnalyserNode) with exponential frequency glides and smooth ADSR envelopes.
  • Safe Master Limiter: A DynamicsCompressorNode caps maximum output gain so high values never cause startling loudness.

Verified Data Sources & Disclaimers

Note: Datasets bundled in this standalone web application are curated static annual snapshots compiled from official NASA and NOAA public records through 2025 (not a live satellite telemetry feed).

  • Global Surface Temperature (1880–2025): NASA Goddard Institute for Space Studies (GISS) Surface Temperature Analysis (GISTEMP v4 / GLB.Ts+dSST), °C anomaly vs. 1951–1980 mean.
  • Atmospheric CO₂ (1959–2025): NOAA Global Monitoring Laboratory (GML) Mauna Loa Observatory annual mean dry-air mole fraction (ppm).
  • Arctic Minimum Sea Ice Extent (1979–2025): National Snow and Ice Data Center (NSIDC) / NASA Sea Ice Index September minimum extent (million km²).
  • Global Mean Sea Level (1993–2025): NASA Sea Level Change Team / GSFC satellite altimetry multi-mission record (mm change relative to 1993).
